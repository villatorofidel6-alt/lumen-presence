# Política de seguridad

No publiques Application IDs de terceros, Client Secrets, tokens, cookies, credenciales, códigos de acceso ni archivos de perfil privados en issues. Reporta problemas de forma privada y utiliza ejemplos sintéticos.

Este proyecto no acepta características de self-bot, automatización de cuentas, scraping de mensajes, acceso no autorizado, evasión de controles ni suplantación de identidad.

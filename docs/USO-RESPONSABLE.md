# Uso responsable

Lumen Presence está diseñado para mostrar una Rich Presence de una aplicación que tú mismo creaste y configuraste. El nombre, los assets y los botones deben representar información veraz y no infringir marcas, derechos de terceros ni reglas de Discord.

La aplicación no modifica el avatar, biografía, nombre de usuario, mensajes ni configuración permanente de tu cuenta. Tampoco admite tokens, self-bots, automatización masiva, lectura de mensajes, scraping, acceso a otras cuentas o suplantación.

> La presencia puede ser visible para otros usuarios. Durante el desarrollo, usa datos de prueba y una cuenta de prueba cuando sea apropiado.
